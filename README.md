# Finance Manager (Personal Finance CLI)

Консольное приложение для управления личными финансами, разработанное в рамках курса ООП.

## Функционал
- Регистрация и авторизация пользователей.
- Добавление доходов и расходов по категориям.
- Установка и редактирование бюджетов на категории.
- Оповещения при превышении бюджета (в том числе при достижении 80% лимита).
- Статистика по доходам, расходам и остаткам бюджетов.
- Перевод средств между кошельками пользователей по логину.
- Фильтрация статистики по выбранным категориям.
- Экспорт транзакций в CSV формат.
- Сохранение и загрузка данных в формате JSON (файл `data.json`).

## Архитектура
Проект разделен на слои (паттерн MVC / слоистая архитектура):
- `model` — сущности (User, Wallet, Transaction).
- `repository` — работа с файловой системой (DataStorage).
- `service` — бизнес-логика (AuthService, FinanceService, ReportService).
- `ui` — консольный интерфейс (ConsoleUI).
- `exception` — кастомные исключения (ValidationException).
